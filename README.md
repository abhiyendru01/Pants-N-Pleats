# PantsnPleats

**PantsnPleats** is an e-commerce platform that allows users to shop a curated collection of pants with stylish pleated designs. With PantsnPleats, users can filter products, manage a wishlist and cart, and complete purchases through secure payment processing.


## Features

- **Product Filtering**: Users can search for pants based on color, size, fit, style, and occasion.
- **Wishlist and Cart**: Favorite items can be saved to a wishlist or added directly to the cart for easy access.
- **Responsive Design**: Optimized for a smooth user experience across desktop, tablet, and mobile devices.
- **User Authentication**: Secure signup, login, and logout functionality using JSON Web Tokens (JWT).
- **Admin Dashboard**: Admin users can manage products, categories, and customer orders.
- **Payment Integration**: Razorpay integration provides a secure payment solution.
- **Order Tracking**: Users can monitor their order status post-purchase for a seamless shopping experience.

## Technologies Used

- **Frontend**: Vite + React, Tailwind CSS for styling
- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **HTTP Requests**: Axios for handling API requests
- **Authentication**: JWT (JSON Web Tokens) for secure user authentication
- **Payments**: Razorpay for seamless payment processing
